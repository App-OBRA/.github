# App Obra

O App Obra é uma ferramenta para acompanhar a execução de obras a partir de modelos IFC. Ele reúne a visualização 3D do projeto, a organização dos serviços e o registro do andamento em um só lugar.

## O que estamos desenvolvendo

- Importação de modelos IFC e navegação pelos elementos em 3D.
- Organização de etapas, serviços, equipes, prazos e custos.
- Checklist de execução ligado aos elementos do modelo.
- Diário de obra e relatórios para acompanhar o progresso.
- Armazenamento local, uso offline e backups portáteis.

## Desenvolvimento

O código-fonte e as instruções para executar, compilar e verificar o aplicativo estão no repositório [`app-obra`](https://github.com/App-OBRA/app-obra). O projeto requer Node.js 22.13 ou superior; para iniciar o ambiente local, use `npm ci` e `npm run dev`.
